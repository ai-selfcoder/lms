# Go Interview Trainer

Тренажёр для лайв-кодинга задач по конкурентности Go (секция «Платформа», бигтех).
32 задачи из `../tasks.md`, оформленные как на реальном собесе: условие, редактор,
прогон решения через `go test -race`.

## Запуск

```bash
cd trainer
go run .
```

Открой **http://localhost:8080**. Другой порт: `PORT=9000 go run .`

## Как пользоваться

- Слева — список из 32 задач, сгруппированных по топикам. ✓ = решено.
- В центре — условие и редактор (Monaco, как в VS Code).
- **▶ Запустить тесты** или **⌘↵** — твоё решение собирается во временный
  модуль вместе со скрытыми тестами и гоняется через `go test -race`. Снизу —
  полный вывод и вердикт PASS/FAIL.
- Код автосохраняется; прогресс и решения переживают перезапуск сервера.
- Стрелки **← Назад / Дальше →** и клики по списку — навигация между задачами.
- **Сбросить** — вернуть стартовый код задачи.

## Типы задач

- **functional** — реализуй функцию/структуру по сигнатуре; тесты проверяют
  корректность и отсутствие гонок.
- **review** — дан багованный код, найди и почини гонки/утечки/дедлоки; тест
  под `-race` падает, пока баги на месте.

## Устройство

```
trainer/
  main.go        — HTTP-сервер и API (/api/tasks, /api/run, /api/save, /api/reset)
  runner.go      — сборка временного модуля и прогон `go test -race`
  validate.go    — `go run . validate`: гоняет эталоны всех задач (QA-гейт)
  web/index.html — весь UI (Monaco + marked с CDN, без сборки)
  tasks/NN/      — meta.json, description.md, starter.go, solution_test.go,
                   reference.go (эталон, не показывается), support.go (опц.)
  progress/      — автосохранённые решения и solved.json
```

## Проверка целостности

```bash
go run . validate    # все 32 эталона должны пройти через грейдер
```
