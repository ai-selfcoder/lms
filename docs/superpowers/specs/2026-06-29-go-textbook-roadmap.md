# Учебник по Go для джунов — карта (roadmap)

Дата: 2026-06-29
Статус: согласовано (высокоуровнево). Каждый под-проект получает свой спек → план → реализацию.

## Цель

Сделать учебник по Go развёрнутым, красивым и понятным для джунов, написанным
человеческим языком. Добавить интерактив: джун меняет код примера и сразу видит
результат — **полностью в браузере, нулевая нагрузка на сервер**.

Фактчекинг ориентируется на ardanlabs/gotour и Tour of Go по сути, но текст и
структура — свои, без копирования (без копирайт-рисков).

## Жёсткие ограничения

- **Только браузер.** Любое исполнение кода учебника происходит на клиенте.
  Сервер для учебника не задействуется вообще. Существующий серверный грейдер
  (Piston, `/api/run`) обслуживает только проверку задач тренажёра — учебник его
  не трогает.
- Движок исполнения: **yaegi (Go-интерпретатор) скомпилированный в WASM**.
  Не серверный Go, не полный компилятор Go→WASM (слишком тяжёлый).

## Декомпозиция

```
                    ┌─────────────────────────────────────┐
                    │  ПП-1: Playground (yaegi → WASM)     │  ← фундамент
                    │  компонент <Runnable> в MDX          │
                    └───────────────┬─────────────────────┘
                                    │ разблокирует интерактив
                 ┌──────────────────┴──────────────────┐
                 ▼                                      ▼
   ┌──────────────────────────┐         ┌──────────────────────────────┐
   │ ПП-2: Учебник «Go с нуля»│         │ ПП-3: Полировка глав по      │
   │ ~12–16 новых глав, basics│         │ конкурентности (10 глав)     │
   └──────────────────────────┘         └──────────────────────────────┘
```

Порядок: **ПП-1 → ПП-2 → ПП-3** (согласовано).

### ПП-1: Интерактивный playground (фундамент)

Компонент «запускаемый блок кода» в MDX на базе yaegi→WASM в Web Worker.
Детали — в `2026-06-29-playground-wasm-design.md`. Делается первым: разблокирует
интерактив для обоих учебников.

### ПП-2: Вводный учебник «Go с нуля»

Новый раздел/набор глав для джунов: синтаксис, типы, функции, структуры, методы,
интерфейсы, ошибки, срезы/карты, дженерики-введение, введение в горутины.
По духу — Tour of Go / Ultimate Go, но своими словами и с интерактивными
примерами на playground из ПП-1. Существующая книга по конкурентности остаётся
как «продвинутый» уровень. Структура глав и оглавление — отдельный спек.

### ПП-3: Полировка глав по конкурентности

Переписать существующие 10 глав (`content/book/*.mdx`) человеческим языком и
добавить интерактивные примеры. Честно учитываем лимиты yaegi: горутины/каналы/
select — runnable; то, что требует настоящего параллелизма или race-детектора, —
статичный разбор с явной оговоркой (без серверного fallback, т.к. только браузер).

## Что НЕ входит в roadmap

- Перевод проверки задач тренажёра на клиент (она остаётся серверной, отдельный
  контур).
- Шаринг/сохранение сниппетов, мультифайловые проекты, stdin (возможные будущие
  улучшения playground, не в текущем объёме).
