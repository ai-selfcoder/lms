Каналы

Что такое канал

Канал — это типизированный конвейер, через который горутины обмениваются значениями. Это основной способ «не общаться через разделяемую память, а делиться памятью через общение». Создаётся через make:

channels.go
// небуферизованный — ёмкость 0
ch := make(chan int)
// буферизованный — ёмкость 8
buf := make(chan int, 8)

ch <- 42      // отправка
v := <-ch     // приём

Блокировка и направление

Отправка в небуферизованный канал блокируется до тех пор, пока другой горутины не окажется готов получатель. Это даёт синхронизацию по передаче значения.

Грабли: дедлок
Отправка в небуферизованный канал в той же горутине без получателя — мгновенный deadlock. Рантайм паникует: all goroutines are asleep.

Каналы можно ограничивать по направлению в сигнатурах — это документирует намерение и ловит ошибки на этапе компиляции:

ТипЗначение
chan Tдвунаправленный
chan<- Tтолько отправка
<-chan Tтолько приём

Закрытие канала

Закрывает канал всегда отправитель, и только один раз. Приём из закрытого канала возвращает нулевое значение и ok == false. Диапазон range по каналу завершается на закрытии.
