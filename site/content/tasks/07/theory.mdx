## Зачем это на собесе

«Тяжёлая» инициализация ровно один раз, безопасная из сотен горутин, — это
ленивые синглтоны: пул соединений, конфиг, gRPC-клиент, подключение к БД.
Наивный флаг `if !done { init(); done = true }` — гонка, и при гонке `init`
выполнится несколько раз. Интервьюер проверяет знание `sync.Once` и понимание,
что `Once.Do` не только «один раз», но и *заставляет всех ждать* первую
инициализацию.

## Что нужно знать

`sync.Once.Do(f)` гарантирует: `f` выполнится **ровно один раз** за всё время
жизни `Once`, даже если `Do` вызвали одновременно из многих горутин. Остальные
вызывающие **блокируются**, пока первый не завершит `f`, и только потом
продолжают.

```go
var once sync.Once
once.Do(func() { /* выполнится один раз */ })
once.Do(func() { /* уже не выполнится */ })
```

Важно: `Do` *не возвращает* результат `f`. Если `init` отдаёт `error`, её надо
сохранить в поле структуры и вернуть всем — включая тех, кто `init` не выполнял.
Это разновидность мемоизации. Подробнее — [sync: примитивы](/book/sync-primitives).

## Идиомы и паттерны

- **`Once` + поле под результат.** `once sync.Once` и `err error` рядом; в
  `Do(func(){ err = init() })`, затем `return err`.
- **Конструктор хранит `init`.** `NewInitializer(init)` кладёт функцию в поле,
  `Do()` оборачивает её в `once.Do`.
- **Барьер видимости.** `Once.Do` устанавливает happens-before: запись в `err`
  внутри `f` гарантированно видна всем, кто вернулся из `Do` после. Отдельная
  синхронизация для `err` не нужна.

## Подводные камни

- **Ручной флаг вместо `Once`.** `if !i.done { ... }` без атомиков/локов —
  гонка: `init` может выполниться 2+ раза, тест `calls == 1` упадёт.
- **Возврат `err` без `Once`.** Если читать/писать `err` вне `Do`, можно
  прочитать «недописанную» ошибку — гонка по памяти. Запись в `err` только
  внутри `Do`, чтение — после возврата из `Do`.
- **Паника в `f`.** Если `init` паникует, `Once` считает попытку выполненной
  (повторно `f` не запустит), а паника пробьётся наверх. Иногда это
  нежелательно — но для задачи `init` возвращает `error`, а не паникует.
- **`sync.Once` нельзя копировать** после использования и нельзя «сбросить».
  Нужен повтор — это уже другой примитив (`singleflight`, отдельный `Once` на
  попытку).

## Как подступиться

1. Структура: `once sync.Once`, `init func() error`, `err error`.
2. `NewInitializer(init)` сохраняет `init` в поле.
3. `Do()`: `i.once.Do(func(){ i.err = i.init() })`, затем `return i.err`.
4. Проверь мысленно: 200 горутин зовут `Do()` одновременно → `init` отработала
   один раз, все получили одинаковую `err`; повторный `Do()` тоже отдаёт ту же
   ошибку и не запускает `init`.
