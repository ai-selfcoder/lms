Реализуй планировщик **Round Robin**.

Функция `Schedule(jobs []Job, quantum int) []string` должна вернуть *потактовый
таймлайн*: срез, где на каждую единицу времени стоит имя задачи, занимавшей CPU.

Правила:

- все задачи готовы с момента 0 и обслуживаются по кругу в порядке передачи;
- каждая задача получает не больше `quantum` единиц подряд, после чего уходит в
  конец очереди (если ей ещё осталось считать);
- `quantum >= 1`.

```go
Schedule([]Job{{"A", 3}, {"B", 3}}, 1)
// → ["A","B","A","B","A","B"]

Schedule([]Job{{"A", 5}, {"B", 3}}, 2)
// → ["A","A","B","B","A","A","B","A"]
```

Тип `Job` уже определён (поля `Name`, `Burst`). Сверить интуицию помогает
[симулятор планировщика](/os/sim/scheduler) — переключи политику на RR.
