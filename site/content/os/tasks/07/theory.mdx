## Зачем спинлок

Когда несколько горутин пишут в одну переменную (`counter++`), операция `++` на
самом деле состоит из трёх шагов: прочитать, прибавить, записать. Если две
горутины вклинятся между этими шагами — часть инкрементов потеряется. Это
**гонка данных**, и результат становится недетерминированным.

Чтобы инкремент был **атомарным с точки зрения логики**, его оборачивают в
критическую секцию, в которую пускают строго по одному. Самый простой замок —
**спинлок**: горутина крутится в цикле («спинит»), пока не захватит замок.

## CAS как сердце замка

Спинлок строится на атомарной инструкции **Compare-And-Swap (CAS)**. Идея:
держим `int32`, где `0` — свободно, `1` — занято.

```text
захват:    крутимся, пока CAS(lock, 0, 1) не вернёт true
           (то есть: "если lock == 0, поставь 1" — атомарно)
критсекция: counter++
отпускание: Store(lock, 0)
```

CAS важен потому, что «проверить, что свободно» и «занять» происходят **одной
неделимой операцией процессора**. Если просто писать `if lock == 0 { lock = 1 }`,
две горутины могут одновременно увидеть `0` и обе зайти в секцию — замок не
работает.

## Пошаговый подход

1. Заведи `var lock int32` (общий) и `counter int` (общий).
2. Заведи `sync.WaitGroup`, на каждую горутину сделай `wg.Add(1)`.
3. Внутри горутины в цикле `perGoroutine` раз:
   - крутись: `for !atomic.CompareAndSwapInt32(&lock, 0, 1) {}`;
   - выполни `counter++`;
   - отпусти: `atomic.StoreInt32(&lock, 0)`.
4. В конце горутины — `wg.Done()` (удобно через `defer`).
5. После запуска всех горутин — `wg.Wait()` и `return counter`.

## Грабли

- **`lock` и `counter` должны быть общими.** Передавай их по указателю /
  захватывай замыканием, а не копируй внутрь каждой горутины.
- **Захват переменной цикла.** Тело горутины не зависит от номера `g`, поэтому
  классическая ловушка с `g` тут не страшна, но привычку «передавай параметр
  явно» лучше держать.
- **Не забудь отпустить замок.** Если выйти из секции без `Store(0)`, остальные
  горутины зависнут в цикле навсегда.
- **`counter++` без замка не пиши** — даже если кажется, что «быстро». Запусти
  тесты с `-race`, чтобы убедиться: гонок нет.
- **0 горутин — это валидно.** Цикл просто не выполнится, `wg.Wait()` вернётся
  сразу, результат `0`.
