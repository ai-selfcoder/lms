Посчитай **среднее время оборота** при планировании по **SJF** (Shortest Job
First, без вытеснения).

Все задачи готовы с момента 0. Время оборота задачи — это момент её завершения.
SJF выполняет задачи в порядке возрастания `Burst`, поэтому короткие финишируют
раньше и средний оборот минимален.

```go
AvgTurnaround([]Job{{"A", 5}, {"B", 3}, {"C", 1}})
// порядок C,B,A → завершения 1, 4, 9 → (1+4+9)/3 = 4.6666...
```

Для пустого среза верни `0`. Тип `Job` уже определён (`Name`, `Burst`).

Подсказка: достаточно отсортировать длительности и пройтись «часами», накапливая
момент завершения каждой задачи.
